# Day 4 Projects

<div class="page-lead">Three capstone demonstrations from the final day of the workshop. Each sits in a different academic tradition — STEM pedagogy, research methods, and philology — and each asks the same question: what does Claude Code open up that wasn't previously available to a single faculty member?</div>

---

## [Physics Interactives]({{ site.baseurl }}/gallery/day-4/becca-interactives/)

PhET-style interactive simulations as single-file HTML pages — authored by faculty using the `/phet-sim` skill. The kind of artifact that historically required a development team is now available to a faculty member with an afternoon.

Includes: Bayesian update sliders, Monty Hall simulators, truth table widgets, Venn diagrams, recursion tree visualizers, Prim's algorithm steppers, and more.

---

## [How to Build an MCP]({{ site.baseurl }}/gallery/day-4/how-to-build-an-mcp/)

A walkthrough for building a Model Context Protocol server — the mechanism that lets Claude Code connect to external tools, APIs, and data sources. The workshop's Replicate image generation integration is one example.

---

## [Project Overviews]({{ site.baseurl }}/gallery/day-4/project-overviews/)

Three written project overviews, each in two formats (HTML and Markdown):

- **Interview coding** — Mary Waters' flexible coding approach, scaled with Claude Code
- **Physics interactives** — the simulation lineage from PhET to faculty-authored HTML
- **Texts and translation** — LLM-assisted close work across Homer, Sanskrit poetics, and multilingual corpora

Each overview has three essays: `summary`, `tradition`, and `affordance`.
