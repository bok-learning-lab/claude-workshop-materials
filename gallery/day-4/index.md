# Day 4 Projects

<div class="page-lead">Two capstone demonstrations from the final day of the workshop — each asking what a faculty member with Claude Code and an afternoon can now produce.</div>

---

## [Becca's Interactives]({{ site.baseurl }}/gallery/day-4/becca-interactives/)

PhET-style interactive simulations as single-file HTML pages, authored by faculty using the `/phet-sim` skill. The kind of artifact that historically required a development team is now available to a faculty member with an afternoon.

Includes: Bayesian update sliders, Monty Hall simulators, truth table widgets, Venn diagrams, recursion tree visualizers, Prim's algorithm steppers, and more.

---

## [Project Overviews]({{ site.baseurl }}/gallery/day-4/project-overviews/)

Three written overviews — qualitative interview coding, interactive simulations, and LLM-assisted work with texts across languages. Each has a summary, a tradition essay, and an affordance essay.
