# Becca's Interactives

<div class="page-lead">PhET-style interactive simulations, authored by faculty in the workshop using the <code>/phet-sim</code> skill. Each is a standalone single-file HTML page — no build step, no dependencies, open in any browser.</div>

## The tools

These were built for a discrete mathematics and probability course. They're included here as examples of the kind of interactive artifact that a faculty member with Claude Code can now produce in a single afternoon.

*Each link below opens the widget in a new tab — they're self-contained HTML files outside the site chrome, so opening them in place would lose the sidebar context. Click around and close the tab when done.*
