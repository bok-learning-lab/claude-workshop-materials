# Day 1 — What's an LLM doing? What's it bad at?

<div class="page-lead">The opening session. The day's purpose was to make the basic shape of these systems visible: how they read (as tokens, not words), where they fail (arithmetic without code, literary analysis without text), and how to set them up to do good work (give them the source material; let them write code when computation matters). Faculty ran the five core <a href="{{ site.baseurl }}/activities/#activities">Activities</a> in the morning and built their first project — the recipe-cards site — in the afternoon.</div>
