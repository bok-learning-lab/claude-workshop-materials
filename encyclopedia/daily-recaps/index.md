# Daily Recaps

<div class="page-lead">Each day of the workshop closed with a handout (or three) and a written distillation — the "Top Tips" or "Key Takeaways" doc faculty could read in five minutes to consolidate what they had just seen. Both the printable handouts and the reading-layout takeaways live here, organized by day.</div>

The handouts are designed in the Bok Center / Learning Lab house style — Inter typeface, red as the only accent, black-and-white print-ready — and ship as both a self-contained HTML page (open in any browser) and a vector PDF (print on letter or tabloid). The Key Takeaways docs are written in the same voice as the morning briefings, with each item leading on a one-sentence headline and grounded in what *actually happened* in the room — the demos, the analogies, the lines worth quoting.

---

## [Day 1 — What's an LLM doing? What's it bad at?](day-1/)

The first session. Recipe-card demos, the multiplication failure, the close-reading rescue, the population-pyramids pivot to code. Handouts: a welcome roadmap for the week, the "it's all text" framing, and the recipe-card walkthrough. Plus Day 1 Top Tips and Key Takeaways.

## [Day 2 — Setup and the Claude Code interface](day-2/)

The day that lays the foundation. Installing Claude Code, opening a project, the terminal refresher, the git mental model. Handouts: terminal refresher, claude-code commands, and git conceptually. Plus Day 2 Key Takeaways.

## [Day 3 — Skills, prompts, and the workshop's own pipeline](day-3/)

Skills as reusable prompts. The class-summarizer demo (the very pipeline producing these takeaways docs). Paper-to-teaching workflows, signature pedagogy, SMART text search. Handouts: claude-code commands and concepts. Plus Day 3 Key Takeaways.

## [Day 4 — MCPs, security, and what's next](day-4/)

Connecting Claude to external systems (Harvard Art Museums, arXiv, Replicate), prompt injection as a real threat model, the responsibility of write access. Handouts: a faculty-facing MCP overview, a longer MCP deep-dive, and a security-concerns handout faculty should keep next to their first MCP install.
