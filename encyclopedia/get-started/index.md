# Get Started

<div class="page-lead">Three doors onto Claude: the <strong>web browser</strong>, the <strong>desktop app</strong>, and <strong>Claude Code</strong> in your code editor / terminal. Pick the door that matches what you're doing today; most workshop participants start with the browser, then add the desktop app, then add Claude Code.</div>

## Claude.ai (Web Browser)

The lowest-friction way in: nothing to install, just sign in and start a chat.

**[Claude.ai Setup]({{ site.baseurl }}/encyclopedia/get-started/claude-ai-setup/)** — Activating your Harvard Edu Enterprise account, signing in with HUIT SSO, and confirming you're on the right workspace.

## Claude Desktop App

The desktop app gives you **Cowork** (point Claude at folders on your computer) and the ability to start **local Claude Code sessions** without leaving the app.

**[Cowork Setup]({{ site.baseurl }}/encyclopedia/get-started/claude-cowork-setup/)** — Opening Cowork, setting up projects that read and write files on your machine, and running three concrete projects end-to-end.

**[Claude Code from the Desktop App (Windows)]({{ site.baseurl }}/encyclopedia/get-started/claude-code-from-desktop-app-windows/)** — Fixing the two things that commonly block local sessions on Windows: Git for Windows (everyone needs this) and CPU virtualization in BIOS (only some machines).

## Claude Code (IDE / Terminal)

Claude Code runs in **VS Code** and the terminal. You see every file it reads, every command it runs, and every line of code it writes — no black box.

**[Claude Code — Overview Guide]({{ site.baseurl }}/encyclopedia/get-started/claude-code-setup/)** — What Claude Code is, how it differs from claude.ai and Cowork, how to install it, and how to orient yourself in VS Code. Start here before the platform-specific guides.

**[Mac Setup]({{ site.baseurl }}/encyclopedia/get-started/claude-code-mac-setup/)** — The exact, copy-pasteable commands for macOS.

**[Windows Setup]({{ site.baseurl }}/encyclopedia/get-started/claude-code-windows-setup/)** — The exact, copy-pasteable commands for Windows via WSL.

**[Setup Checklists]({{ site.baseurl }}/encyclopedia/get-started/checklists/)** — One-page printable checklists for Mac and Windows.

---

> **Not sure which to start with?** Use Claude.ai first — it needs no installation. Once you're comfortable with prompting and have run through the activities, come back for the desktop app and then Claude Code.
