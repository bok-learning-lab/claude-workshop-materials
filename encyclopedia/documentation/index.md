# Documentation

<div class="page-lead">Reference docs compiled for the workshop — two sets: overview guides covering Claude Code from scratch, and the full official documentation compiled from the Anthropic docs site.</div>

## [Overview Guides]({{ site.baseurl }}/encyclopedia/documentation/overview/)

Ten structured guides covering Claude Code from the ground up: what it is, how to get started, best practices, common workflows, memory and CLAUDE.md, CLI reference, slash commands, settings, and prompt engineering. Good reading order for someone who has done setup and wants to go deeper.

## [Official Docs Reference]({{ site.baseurl }}/encyclopedia/documentation/official/)

Nine reference documents compiled from the official Claude Code documentation (`code.claude.ai`), including the full `llms.txt` index, context window details, output styles, path-specific rules, extending Claude Code, subagents, and best practices. More technical than the overview guides — useful as a reference during actual Claude Code sessions.
